# AjilBot - Chatbot AI Engineering (Gemini AI)
## Cara menjalankan

1. Install dependencies:
   ```
   npm install
   ```
2. Salin `.env.example` menjadi `.env`, lalu isi API key Gemini kamu:
   ```
   GEMINI_API_KEY=isi_dengan_api_key_asli
   ```
3. Jalankan server:
   ```
   npm start
   ```
4. Buka browser: http://localhost:3000
